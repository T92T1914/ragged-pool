Python, C++ and framework integration

Different group sizes.
One summary each.

A model can receive two items in one group, three in another and none in the next. This small PyTorch layer turns each group into one vector, using learned scores to decide how much each item contributes.

C++ implements the CPU forward and backward operations. Python supplies a readable reference and connects the native operation to training. This is a learning and integration project, with no new algorithm, production need or general speed advantage claimed.

A small arithmetic example

Two vectors, one weighted result

Take one group with vectors [2, 0] and [0, 4]. Give them scores 0 and log(3). Softmax produces weights 0.25 and 0.75.

  1. Normalize within the group. Maximum subtraction keeps the softmax calculation stable without changing its weights.
  2. Weight the features. One quarter of [2, 0] is [0.5, 0]. Three quarters of [0, 4] is [0, 3].
  3. Add them. The group's summary is [0.5, 3]. An additional empty group has summary [0, 0] and zero input gradients.
values  = [[2, 0], [0, 4]]
logits  = [0, log(3)]
offsets = [0, 2, 2]
output  ≈ [[0.5, 3], [0, 0]]

This worked example has group sizes two and zero. The diagram also shows a separate three-item group. These numbers explain the operation; this page performs no native calculation or training in your browser.

The bounded CPU contract

ragged_pool(values, logits, offsets) accepts contiguous CPU float32 or float64 values [N,D], matching logits [N] and contiguous int64 offsets [B+1]. Offsets start at zero, end at N and never decrease. Empty groups and an entirely empty batch are supported.

The declared bounds are N ≤ 4096, B ≤ 128 and 1 ≤ D ≤ 128. Values and scores must be finite and within [-1000,1000]. Outputs use fresh storage. Inputs are neither changed nor moved between devices.

The native CPU calculation uses float64 accumulation for either input dtype and casts back to that dtype. Its rounding can differ from the ordinary PyTorch reference. This does not promise cross-version ABI compatibility, every platform or every derivative composition.
