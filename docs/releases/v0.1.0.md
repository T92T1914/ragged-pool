# ragged-pool 0.1.0

The first release supplies a bounded CPU PyTorch pooling layer with native C++ forward and backward, first order autograd, fake metadata and a synthetic training consumer.

For each nonempty group, `ragged_pool(values, logits, offsets)` returns the softmax-weighted sum of its feature vectors. Empty groups return zero vectors and contribute zero input gradients. The supported contract is contiguous CPU float32/float64, N <= 4096, B <= 128, D from 1 through 128, finite values/logits within [-1000,1000], and contiguous int64 offsets.

The package targets CPython 3.11.8 and PyTorch 2.9.1+cpu on Windows x64 with MSVC 14.44 and C++17. Install the CPU PyTorch dependency from its official index, then install the release wheel:

```powershell
python -m pip install 'torch==2.9.1+cpu' --index-url https://download.pytorch.org/whl/cpu
python -m pip install --no-deps .\ragged_pool-0.1.0-cp311-cp311-win_amd64.whl
```

The release workflow builds and tests the wheel before publishing. It uses a fresh acceptance environment outside the checkout, compares installed/package source bytes and all three license notices, runs independent mathematical checks separately from registration checks, and executes float32 and float64 consumers that perform an SGD step. The declared compiler path is `aot_eager` with fullgraph forward/backward. It does not establish Inductor optimization.

The attached source archive identifies its exact revision. Public [workflow runs](https://github.com/T92T1914/ragged-pool/actions/workflows/cpu.yml) and the tag record the release execution. [Historical local acceptance](https://github.com/T92T1914/ragged-pool/blob/v0.1.0/docs/acceptance.md) remains separate evidence.
