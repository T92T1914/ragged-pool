# One global objective across two CPU ranks

`examples/train_distributed.py` is a bounded two-rank CPU Gloo/DDP consumer. Its intended route takes two momentum-SGD updates with unequal group counts and then a zero-group rank. Each rank backpropagates two times its local squared-error sum divided by the global group count, so DDP's averaged parameter gradients match the global group mean. Input gradients retain their local scaling.

Linux qualification is pending in the [result record](results/distributed-cpu.json). No successful distributed result is claimed at this source checkpoint. The intended pin is Ubuntu24.04 x86-64/CPython3.11.8/Torch2.9.1+cpu/GCC13/C++17, one numerical thread per worker and two local ranks. Explicit loopback Gloo options use pin-specific bindings through PyTorch's experimental backend registration API. The tested Windows wheel reported Gloo availability but failed before training because it supplied no usable loopback device, including explicit TCP and UV probes. Non-Linux execution is now refused before worker launch. This is not a general distributed runtime, multi-node/GPU route, fault-tolerant service, security hardening or performance result.
