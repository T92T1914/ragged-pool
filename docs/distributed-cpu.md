# One global objective across two CPU ranks

`examples/train_distributed.py` is a bounded two-rank CPU Gloo/DDP consumer. Its intended route takes two momentum-SGD updates with unequal group counts and then a zero-group rank. Each rank backpropagates two times its local squared-error sum divided by the global group count, so DDP's averaged parameter gradients match the global group mean. Input gradients retain their local scaling.

Qualification is pending in the [result record](results/distributed-cpu.json). No successful new distributed result is claimed at this source checkpoint. The intended local pin is Windows x64/CPython3.11.8/Torch2.9.1+cpu, one numerical thread per worker and two local ranks. Explicit loopback Gloo options use pin-specific bindings through PyTorch's experimental backend registration API. Windows distributed support is prototype-level. This is not a general distributed runtime, multi-node/GPU route, fault-tolerant service, security hardening or performance result.
